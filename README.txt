FRESHMART GROCERY STORE — FRONTEND COLLEGE PROJECT

TECHNOLOGIES
HTML5, CSS3, vanilla JavaScript, browser LocalStorage. No backend or framework required.

RUN
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Right-click index.html and choose Open with Live Server.

PAGES
index.html, shop.html, categories.html, offers.html, cart.html, checkout.html, about.html, contact.html

NOTES
- Product photos are loaded from Unsplash URLs; internet access is needed for those photos. CSS and image fallback states help if an image fails.
- Prices, address, phone, email, opening hours, testimonials and offers are sample project content.
- Cart uses LocalStorage. Checkout and contact are frontend demonstrations only; no real orders, payments or messages are sent.
- Demo discount: 5% off subtotal at ₹1,000 or above. Demo delivery: free on eligible totals of ₹500 or above, otherwise ₹40.
